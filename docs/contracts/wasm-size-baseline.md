Tracks the release WASM binary size of every contract so unexpected size
growth (issue #1171) is caught before it lands.

## How to run locally

```bash
# build every contract and diff against this baseline
./scripts/wasm-size-benchmark.sh

# rebuild and rewrite this baseline after an intentional size change
./scripts/wasm-size-benchmark.sh --update

# benchmark a single contract
./scripts/wasm-size-benchmark.sh --contract nft
```

Builds run inside an isolated workspace under `target/wasm-size-bench/`,
so repository files are never modified. A non-zero exit status means a
contract grew by more than the threshold or changed status.
